# 🎮 DOPO 
 
> Laboratorios y talleres de **Diseño Orientado por Objetos** — donde el UML se convierte en código, y el código se convierte en juego.
 
Este repositorio es mi bitácora de experimentación con **Java** y **POO**: desde diagramas de clases dibujados en **Astah** hasta pequeños mundos jugables construidos pieza por pieza. Cada carpeta es un laboratorio distinto, pero todos comparten la misma obsesión: diseñar antes de programar, y programar para entender el diseño.
 
---
 
## 🧩 ¿Qué vas a encontrar aquí?
 
- **Diagramas UML (Astah)** — el mapa antes del territorio. Clases, relaciones, herencia y patrones pensados antes de escribir una sola línea de código.
- **Implementaciones en Java** — donde esos diagramas cobran vida (y a veces se rebelan contra el plan original).
- **Juegos como excusa para aprender** — simuladores, laberintos, tableros y mecánicas simples que ponen a prueba conceptos como encapsulamiento, polimorfismo, herencia y composición.

## 🚀 Filosofía
 
> "Un buen diagrama no garantiza un buen programa, pero un mal diagrama garantiza dolores de cabeza."
 
Cada laboratorio busca responder una pregunta concreta de diseño: ¿cómo evito que una skin rompa el principio de responsabilidad única? ¿cómo hago que un juego sea extensible sin reescribirlo todo?
